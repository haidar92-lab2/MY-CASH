# منافذ الرواتب — دليل الإعداد

## الوضع الحالي
هذي أول مرحلة فعلية من التطبيق: نظام التفعيل + تسجيل الدخول (رقم هاتف + رمز سري 5 أرقام) + استرجاع الرمز عبر واتساب (وضع تجريبي حالياً). الشاشة الرئيسية (الأرباح، الأجهزة، التسويات) تُبنى بالمرحلة الجاية بعد ما نتأكد هذا الأساس شغال تمام.

## خطوة 1: إنشاء مشروع Firebase (مجاني)
1. روح لـ https://console.firebase.google.com
2. أنشئ مشروع جديد، سميه مثلاً "منافذ-الرواتب"
3. من القائمة الجانبية: Build → Firestore Database → أنشئ قاعدة بيانات (اختر وضع production)
4. من Project settings (⚙️) → عام → طبّق "Add app" → اختر الويب (</>) → سجل التطبيق
5. Firebase راح يعطيك كائن `firebaseConfig` — انسخه بالكامل

## خطوة 2: عبّي الإعدادات
افتح `js/firebase-config.js` وحط القيم اللي نسختها من Firebase، وتأكد رقمك الشخصي محطوط بـ `ADMIN_PHONE` (بصيغة دولية بدون +، مثال: 9647716321829) ورقم الدعم بـ `SUPPORT_PHONE`.

## خطوة 3: ارفع قواعد الأمان
من Firebase Console → Firestore Database → Rules، الصق محتوى ملف `firestore.rules` واضغط نشر.

⚠️ **ملاحظة أمان مهمة:** القواعد الحالية مبسطة لأن التطبيق ما يستخدم Firebase Authentication بعد (فقط رقم هاتف + رمز سري مخزن يدوياً). هذا يعني تقنياً أي شخص يعرف تفاصيل مشروعك يكدر يتلاعب بقاعدة البيانات مباشرة. لأول نسخة تجريبية بين عدد محدود من الوكلاء هذا مقبول، لكن قبل ما توسع الاستخدام لازم ننتقل لـ Cloud Functions أو Firebase Authentication عشان الحماية تصير حقيقية. خلني أعرف إذا تحب نسوي هذا التحسين بمرحلة لاحقة.

## خطوة 4: صفحة الأدمن (توليد الأكواد)
افتح `admin.html`، غيّر السطر:
```js
const ADMIN_PASSWORD = "غيّرني123";
```
لكلمة مرور فعلية بس أنت تعرفها، قبل لا تنشر المشروع.

## خطوة 5: النشر على GitHub Pages
نفس أسلوب تطبيق منافذ سويچ:
1. ارفع كل ملفات هذا المجلد لمستودع GitHub
2. من إعدادات المستودع → Pages → فعّل النشر من الفرع الرئيسي
3. الرابط الناتج هو رابط التطبيق اللي تشاركه مع الوكلاء

## خطوة 6: إرسال OTP عبر واتساب (مو مكتمل بعد)
حالياً الكود يظهر على الشاشة مباشرة (وضع تجريبي) بدل ما يرسل عبر واتساب فعلياً — مكتوب "TODO" بملف `js/auth.js` بمكان الإرسال. لتفعيلها فعلياً تحتاج:
- حساب WhatsApp Business API (عبر Meta مباشرة أو وسيط مثل Twilio أو Gupshup)
- بعد ما يصير عندك حساب وأرقام API، أرسللي التفاصيل وأربطها بالكود

## اختبار سريع لدورة العمل
1. افتح `admin.html`، ولّد كود تفعيل
2. افتح `index.html`، دخل الكود بشاشة التفعيل
3. راح تنطلع شاشة "أنشئ حسابك" — سجل رقم هاتف ورمز سري
4. جرب تسجيل خروج ودخول بنفس البيانات
5. جرب "نسيت الرمز السري" — الكود التجريبي راح يطلع على نفس الشاشة (بدل واتساب مؤقتاً)

## الملفات
- `index.html` — التطبيق الأساسي (تفعيل، تسجيل دخول، لوحة مبدئية)
- `admin.html` — صفحتك الخاصة لتوليد أكواد التفعيل
- `js/firebase-config.js` — إعداداتك (لازم تعبيها)
- `js/db.js` — التعامل مع قاعدة البيانات
- `js/auth.js` — منطق التفعيل وتسجيل الدخول
- `firestore.rules` — قواعد الأمان
- `manifest.json` + `service-worker.js` — يخلون التطبيق يشتغل كـ PWA على اندرويد وآيفون
